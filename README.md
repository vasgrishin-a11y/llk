# Дашборд ОППиУ | Лубри-Тех

Интерактивный дашборд оперативного планирования и управления (S&OP) на горизонт
18 месяцев (Окт 2026 – Мар 2028): спрос, поставки, запасы, согласованный план и
цикл принятия решений ОППиУ. Октябрь 2026.

**Стек:** статический HTML + ES-модули, без сборки и без внешних chart-библиотек —
графики рисуются собственным canvas-движком (`src/charts.js`). Работает с любого
статического хостинга (GitHub Pages, nginx, `python3 -m http.server`).

## Быстрый старт

```bash
npm start          # python3 -m http.server 8080
# открыть http://localhost:8080
```

## Вкладки

| Вкладка | Содержимое |
|---|---|
| Обзор | 8 KPI месяца (динамические, пересчитываются из XLSX), график «план/факт/прогноз» 2026–2027, YoY по объёму и выручке/марже, точность прогноза, ключевые отклонения |
| 1. Сегментация | Пузырьковая карта клиентов (Стратегические / Ядро / Перспективные / Транзакционные), распределение выручки, структура затрат |
| 2. Спрос | Спрос против бизнес-плана (переключение 2026/2027), вотерфолл согласованного прогноза, точность/смещение, FVA, сезонность, выбор мат. моделей по сегментам |
| 3. Запасы | Дни покрытия по каналам/продуктам, 18-месячный план запасов, неликвиды (тоннаж/деньги), сырьё и готовая продукция, ABC-XYZ-матрица, MTS/MTO |
| 4. Поставки | Карта цепочки поставок с ограничениями, gap-диаграмма покрытия спроса, 3 сценария (A/B/C, рекомендация C) + радар, веер 18 мес., тепловая карта клиент × продукт (покрытие/маржа, дельты к базе) |
| 5. Планы | 7 под-планов (продажи, производство, перемещения, закупки, запасы, себестоимость, выручка) × фильтр по кварталам |
| 6. Действия | План мероприятий со статусами, вехи, ожидаемый эффект, решение ОППиУ |
| Качество данных | Проверка загруженного набора и его содержимое |

## Принципы

- **Без Chart.js** — 11 типов графиков на чистом canvas (`drawChart`): line, bar,
  stacked, hbar, combo (две оси), area, waterfall, band («веер»), donut, radar, scatter.
- **Конфигурация** — вкладки и KPI описаны в `src/config.js`, отчётные датасеты —
  в `src/datasets.js`, загружаемое помесячное ядро (объём/выручка/цена) — в `src/data.js`.
- **XLSX-загрузка** — файл со схемой `Период, Тип (Факт/Прогноз), План объема,
  Факт объема, План выручки, Факт выручки, Цена` (принимаются и англ. названия).
  KPI и график «Обзора» пересчитаются из него; кнопка «Сбросить» возвращает демо.
- **Демо-данные** воспроизводят годовой отчёт «Лубри-Тех»: помесячные ряды — это
  индексы динамики, официальные YTD-итоги (880/900 тыс. кЛ, 320,5/342 млн руб.)
  зафиксированы в `CANON` (`src/data.js`).
- **UX** — дизайн-система в стиле дашборда `inplan-dashboard`: тёмный верхний
  рельс-меню (боковой панели нет), только светлая тема, адаптивная сетка,
  сворачиваемые таблицы «📋 Данные», локальные переключатели-чипы на вкладках.
  Действия «Загрузить Excel» и «Сбросить» — ненавязчивые икон-кнопки в шапке.
- **Доступность** — у каждого canvas `role="img"` + `aria-label`, у KPI и
  икон-кнопок — подсказки при наведении.
- **Состояние** (выбранная вкладка) сохраняется в `localStorage`.
- **ClickHouse** — `src/clickhouse.js` оставлен как точка расширения для запросов
  к БД (в демо не используется).

## Структура

```
index.html        каркас + дизайн-система In.Plan (CSS-токены, только светлая тема)
src/app.js        сборка экранов вкладок, события, XLSX, состояние
src/charts.js     canvas-движок графиков (11 типов)
src/config.js     метаданные: название, вкладки, KPI с подсказками
src/data.js       помесячное ядро + normalizeRows/filterData/summary/CANON
src/datasets.js   отчётные датасеты вкладок (1–6)
src/storage.js    обёртка localStorage
src/clickhouse.js адаптер HTTP-запросов (резерв интеграции)
assets/           xlsx.full.min.js и общие вспомогательные модули
```

## Стиль и дизайн

Оформление повторяет дашборд [`inplan-dashboard`](https://github.com/vasgrishin-a11y/inplan-dashboard):
Open Sans, тёмный рельс-меню **только сверху** (горизонтальные вкладки с
акцентным подчёркиванием), только светлая тема, «hairline»-карточки с тонкими
границами, плотные таблицы, чип-переключатели и икон-кнопки действий в шапке
(загрузка Excel / сброс до демо — без текстовых плашек, чтобы не отвлекали).
Фирменный акцент «Лубри-Тех» `#20A7C9` и статусные цвета аналитического
контента (зелёный `#4CAF50`, жёлтый `#FF9800`, красный `#D93025`,
нейтральный `#8c9bae`) сохранены — они несут смысловую нагрузку в сегментах,
тепловых картах и сценариях.
