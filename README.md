# Ежемесячный цикл IBP · In.Plan

Интерактивный дашборд интегрированного бизнес-планирования (S&OP / IBP) на горизонт 18 месяцев: спрос, поставки, запасы, согласованный план и цикл принятия решений. Текущий цикл — октябрь 2026.

**Масштаб модельного бизнеса:** производство ~527 тыс. т (2025), выручка ~75 млрд руб., чистая прибыль ~10 млрд руб. (валовая маржа ~23%).

**Стек:** статический HTML + ES-модули, без сборки и без внешних chart-библиотек — графики рисуются собственным canvas-движком (`src/charts.js`). Работает с любого статического хостинга.

## Быстрый старт

```bash
npm start          # python3 -m http.server 8080
# открыть http://localhost:8080
```

## Вкладки

| Вкладка | Содержимое |
|---|---|
| Обзор | 8 KPI, график «бизнес-план / факт / S&OP предыдущего цикла / требуется в 4 кв. для годового плана», YoY по объёму и выручке/марже, точность прогноза (WAPE), ключевые отклонения |
| 1. Сегментация | Полосы сегментов по 21 клиенту (Бриллиант → Бронза), размер круга — валовая прибыль, фильтры по каналу продаж и «на пересмотр», таблица клиентов, интерактивный донат выручки (7 каналов + прочие = 74 000 млн руб.) и затраты по каналам |
| 2. Спрос | Неограниченный спрос против бизнес-плана (динамические KPI по годам), waterfall согласованного прогноза (134 600 + 10 200 + 7 200 = 152 000 т), тепловая карта WAPE по категориям, смещение, FVA, сезонность, выбор математических моделей |
| 3. Запасы | Покрытие по каналам/продуктам (страховой запас заливкой), план запасов 18 мес. (тонны / млн руб. / отклонение от цели; запас ≈ +20% к цели), неликвиды, сырьё и ГП, ABC-XYZ, MTS/MTO |
| 4. Поставки | Карта цепочки (5 поставщиков → 5 заводов → 5 заводских складов → 12 складов 3PL; разрывы — красным, узкие места — жёлтым), gap-диаграмма, ограничения, сценарии А/Б/В с аналитикой выполнения годового плана 2026, тепловая карта клиент × продукт |
| 5. Планы | 7 под-планов: продажи, производство, перемещения, закупки, запасы, себестоимость, выручка. Детализация до нижнего уровня (месяц × канал × категория / завод / маршрут / склад) |
| 6. Действия | План мероприятий, статусы, вехи, ожидаемый эффект и итоговое решение |

Раздел «Качество данных» удалён: в текущей версии оставлены только рабочие разделы цикла IBP.

## Единицы и связность данных

- Объём — **тонны**.
- Деньги — **млн руб.**
- Цена — **руб/т** (средняя 2026: 141 500 руб/т, 2025: 142 300 руб/т).
- Базовая формула: `выручка, млн руб. = объём, т × цена, руб/т / 1 000 000`.
- Сценарии пересчитаны так, чтобы абсолютная маржа соответствовала проценту маржи.
- Разрыв предложения 4 кв. 2026: 152 000 − 19 000 = 133 000 т (сценарий А «Базовый», без компенсирующих мер).
- Сценарии 4 кв. 2026: А — 133 000 т / 18 820 млн / ВП 4 517 млн (24,0%); Б — 152 000 т / 21 510 млн / ВП 4 625 млн (21,5%); В (утверждён) — 133 000 т / 18 820 млн / ВП 5 150 млн (27,4%).
- Год 2026 при сценарии В: 523 000 т / 74 005 млн руб. / ВП 17 811 млн руб. против бизнес-плана 546 000 т / 78 624 млн / ВП 19 046 млн.
- Точность прогнозирования — слабое место кейса: WAPE 16,4% (3 кв. 2026) при цели ≤10%.

## Принципы

- **Без Chart.js** — 11 типов графиков на чистом canvas (`drawChart`): line, bar, stacked, hbar, combo, area, waterfall, band, donut, radar, scatter.
- **Конфигурация** — вкладки и KPI описаны в `src/config.js`, отчётные датасеты — в `src/datasets.js`, загружаемое помесячное ядро — в `src/data.js`.
- **XLSX-загрузка** — схема: `Период, Тип (Факт/Прогноз), План объема, Факт объема, План выручки, Факт выручки, Цена`.
- **UX** — дизайн-система In.Plan: тёмный rail, фирменный фиолетовый акцент, Open Sans, светлая тема, карточки с тонкими границами, плотные таблицы, чип-переключатели и икон-кнопки.
- **Доступность** — у canvas есть `role="img"` и `aria-label`, у KPI и икон-кнопок — подсказки при наведении.
- **Состояние** выбранной вкладки сохраняется в `localStorage`.

```
src/storage.js    обёртка localStorage

assets/           xlsx.full.min.js
```
